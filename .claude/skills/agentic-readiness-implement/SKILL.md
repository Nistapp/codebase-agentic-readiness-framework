# Implement the fixes from an audit report (pointer)

This skill is a pointer. The recipe lives in this repository at `implement/SKILL.md`.

1. Read `implement/SKILL.md` in full and follow it exactly. It is the only source of the steps and the rules.
2. Run every command from the root of this repository: the folder that holds this `.claude/` folder.
3. The repository to change is the path the user names. The audit report is the JSON file the user names. It must
   be a final report from the audit recipe. If either path is missing, ask for it before Stage 0.
