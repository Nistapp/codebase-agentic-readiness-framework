# Audit a repository (pointer)

This skill is a pointer. The recipe lives in this repository at `audit/SKILL.md`.

1. Read `audit/SKILL.md` in full and follow it exactly. It is the only source of the steps and the rules.
2. Run every command from the root of this repository: the folder that holds this `.claude/` folder.
3. The repository to audit is the path the user names. The output directory is the path the user names for the
   output. If the user did not name one, ask for it in Stage 0. Never write inside the audited repository.
