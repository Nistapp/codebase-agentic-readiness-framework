# Tool Catalogue

Generated by `recipe_lint.py <root> --write-catalogue` from every tool's own `--describe` output: the tools in `audit/tools/` sorted by name, then the tools in `implement/tools/` sorted by name. Do not edit by hand: a stale file fails `make check`.

## engine.py

**Version:** 0.1.0  
**Writes:** One file, <label>.engine-report.<stamp>.json, in --out-dir (default: the current directory), which must be outside the target. With --emit-baseline, also do-not-do.draft.md beside it. A name that is taken is never replaced.

Run the deterministic audit engine from any directory; the report is named for the repository.

```text
engine.py <target> [--out-dir DIR] [--repo-label LABEL] [--phase N] [--exclude GLOB]... [--max-files N] [--run-gates --allow-probe VERB... [--timeout SECONDS]] [--emit-baseline] [--no-user-config]
engine.py --list-checks
```

## facts.py

**Version:** 0.1.0  
**Writes:** One new file, the one --out names, which must be outside the target and must not exist. It is never replaced.

Describe a repository with counts and names and no verdicts, as facts.json. Writes facts_version, label, git, inventory, stack, instruction_files, components, size and caps.

```text
facts.py <target> --out FILE [--repo-label LABEL] [--exclude GLOB]... [--max-files N]
```

## render_report.py

**Version:** 0.1.0  
**Writes:** <md>, the path given by --out: a new file, never a replacement, and never inside the audited target. The report is only read.

Render an audit report to Markdown. The Markdown is a pure function of the JSON report.

```text
render_report.py <report> --out <md>
```

## report.py

**Version:** 0.1.0  
**Writes:** init: a new draft, <label>.audit-draft.<stamp>.json, in the intake's output_dir, which must be outside the target; a name that is taken is never replaced. import-engine, add-check, add-finding, set-disposition and set-stack-profile: that draft, in place and atomically, and no other file. status: nothing. finalise: a new final report, <label>.audit-report.<stamp>.json, and its Markdown, <label>.audit-report.<stamp>.md, beside the draft, which it leaves as it was.

Build the audit report: the only writer of the draft, and every write is validated.

```text
report.py init <intake>
report.py import-engine <draft> <engine report>
report.py add-check <draft> --from FILE|-
report.py add-finding <draft> --from FILE|-
report.py set-disposition <draft> --via VIA (--finding ID --disposition D [--note TEXT] | --from FILE|-)
report.py set-stack-profile <draft> <id> [--derived] [--confirmed]
report.py status <draft>
report.py finalise <draft>
```

## progress.py

**Version:** 0.1.0  
**Writes:** Only in the workspace, the report's folder, which must be outside the target: <label>-agentic-readiness-state.json (init) and <label>-agentic-readiness-STATE.md (init, render, and any command given --render), each replaced atomically. init never replaces a state; show writes nothing; every other command rewrites the JSON after validating it.

Create, show and render the implement recipe's per-repository state from a final audit report.

```text
progress.py init --report REPORT --target REPO [--default-branch BRANCH] [--phase PHASE] [--date YYYY-MM-DD] [--framework-rev SHA]
progress.py show --workspace DIR [--label LABEL] [--json]
progress.py render --workspace DIR [--label LABEL]
progress.py set-status FINDING STATUS --workspace DIR --phase PHASE [--commit SHA] [--verification-command CMD --verification-result TEXT] [--debt what=..,count=N[,baseline=FILE]] [--clear-debt] [--reason TEXT] [--note TEXT] [--by owner|agent] [--date YYYY-MM-DD] [--label LABEL] [--render]
progress.py skip|defer FINDING --reason TEXT --by owner --workspace DIR --phase PHASE [--render]
progress.py unskip|undefer FINDING --by owner --workspace DIR --phase PHASE [--reason TEXT] [--render]
progress.py pref set KEY VALUE --reason TEXT --by owner --workspace DIR --phase PHASE [--render]
progress.py pref unset KEY --reason TEXT --by owner --workspace DIR --phase PHASE [--render]
progress.py theme THEME --status branch_open|pr_open|merged [--branch B] [--pr N] [--merged-sha SHA] --workspace DIR --phase PHASE [--render]
```
