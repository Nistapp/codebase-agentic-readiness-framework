# Tool Catalogue

Generated by `recipe_lint.py <root> --write-catalogue` from every tool's own `--describe` output, sorted by name. Do not edit by hand: a stale file fails `make check`.

## build_skills.py

**Version:** 0.1.0  
**Writes:** dist/skills/agentic-readiness-audit/ (SKILL.md, references/, scripts/), replaced whole on each run; --out-dir changes where dist/skills/ itself goes.

Build the agentic-readiness-audit skill bundle under dist/skills/.

```text
build_skills.py [--out-dir DIR]
```

## engine.py

**Version:** 0.1.0  
**Writes:** One file, <label>.engine-report.<stamp>.json, in --out-dir (default: the current directory), which must be outside the target. With --emit-baseline, also do-not-do.draft.md beside it. A name that is taken is never replaced.

Run the deterministic audit engine from any directory; the report is named for the repository.

```text
engine.py <target> [--out-dir DIR] [--repo-label LABEL] [--phase N] [--exclude GLOB]... [--max-files N] [--run-gates --allow-probe VERB... [--timeout SECONDS]] [--emit-baseline]
engine.py --list-checks
```

```text
facts.py <target> --out FILE [--repo-label LABEL] [--exclude GLOB]... [--max-files N]
```

## render_report.py

**Version:** 0.1.0  
**Writes:** <md>, the path given by --out: a new file, never a replacement, and never inside the audited target. The report is only read.

Render an audit report to Markdown. The Markdown is a pure function of the JSON report.

```text
render_report.py <report> --out <md>
```

## report.py

**Version:** 0.1.0  
**Writes:** init: a new draft, <label>.audit-draft.<stamp>.json, in the intake's output_dir, which must be outside the target; a name that is taken is never replaced. import-engine, add-check, add-finding and set-disposition: that draft, in place and atomically, and no other file. status: nothing. finalise: a new final report, <label>.audit-report.<stamp>.json, and its Markdown, <label>.audit-report.<stamp>.md, beside the draft, which it leaves as it was.

Build the audit report: the only writer of the draft, and every write is validated.

```text
report.py init <intake>
report.py import-engine <draft> <engine report>
report.py add-check <draft> --from FILE|-
report.py add-finding <draft> --from FILE|-
report.py set-disposition <draft> --via VIA (--finding ID --disposition D [--note TEXT] | --from FILE|-)
report.py status <draft>
report.py finalise <draft>
```
