## The ratchet

`make self-audit` runs the engine against `.audit-baseline.json`. The comparison is by finding id
([ADR-0001](../../deterministic-audit/docs/architecture/adrs/0001-report-not-a-gate.md)): the run exits 2 only when a
finding appears that the baseline did not have, and 0 otherwise. Fixing a finding never fails the run. CI runs it as
the `self-audit` job on Linux, and `CI Gate` needs it.

To check that the ratchet bites, a scratch copy of the tracked files with `.python-version` removed makes the run
exit 2 and name the regression `EXEC-01:python`.

## Reproduce

From the repository root, with Python 3.11+ and `uv` (see `make setup`):

```bash
make self-audit             # reads the repository, writes dist/self-audit/audit-report.{json,md}; exit 2 on a regression
cat dist/self-audit/audit-report.md
```

Nothing is written inside the tracked tree: `dist/` is git-ignored. The report differs from the published one only in
`provenance.scanned_at`, the target path and the commit.

## Keep it true

When a finding is fixed, accept the smaller baseline on purpose:

```bash
make update-audit-baseline  # rewrites .audit-baseline.json from a fresh run; review the diff
```

Never run it to get a failing `make self-audit` green: a new finding is fixed or recorded with an owner reason here
first. After updating it, copy the report to `schema/examples/self-audit/<date>.json`, update the tables above,
and run `make update-secrets-baseline` (the report holds a ruleset hash and a git SHA that read as high-entropy
strings), reviewing the diff.
